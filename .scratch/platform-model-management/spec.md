# 平台管理员模型管理页面

状态：设计讨论中，尚未开始功能实现。

## 预期结果与范围

平台管理员能够通过页面新增、编辑、启用和禁用平台模型，省去直接调用目录维护接口的步骤。本次范围来自用户明确提出的四项操作。

## 已查证的基线

- AI 服务已有平台目录维护接口，网关路径为 `/ai-platform/models`，使用 Platform 身份与 `platform:ops:manage` 权限。租户身份不能维护平台目录。见 [模型接口契约](../../docs/model-api.md)。
- 当前 AI Sub-App 是租户工作台，模型页只保存租户模型选择。见 [工作台说明](../../docs/sub-app-workspace.md) 与 [模型页实现](../../ai-sub-app/src/ModelManagement.vue)。
- 现有 [ADR 0005](../../docs/adr/0005-platform-managed-secrets.md) 规定真实模型密钥由部署环境注入，AI 数据库只存引用；浏览器不接收原始密钥。
- 模型响应不含密钥引用，而现有编辑请求要求重新提供密钥引用。这会影响普通编辑和启停操作，需要在页面方案确定后明确更新语义。
- SaaS Forge 平台控制台位于 `frontend/apps/platform-console`，采用静态本地路由与菜单，现有布局明确不承载 Sub-App；平台客户端已有 `usePlatformClient()`，权限码已有 `platform:ops:manage`。按当前机制接入，需要修改 SaaS Forge 平台前端；不能直接把租户模型页挂到平台身份下。
- 平台禁用模型后，新会话、新回合和后续代理模型调用会重新检查状态。已打开的模型 SSE 转发不逐批检查目录状态，因此禁用不保证立即中断正在输出的内容。
- 目录保存和启用不验证供应商连通性；密钥引用允许列表与实际密钥在模型代理调用时检查。

## 页面简报（待确认）

- 使用者：有平台运维权限的平台管理员。
- 主任务：接入模型并维护平台模型目录。
- 主操作：新增模型；编辑和启用、禁用放在列表行操作中。
- 首屏信息：模型名称、提供方、模型标识、状态、能力与上下文窗口；接入地址和密钥引用放在编辑表单。
- 页面原型：沿用平台控制台现有列表规范，新增与编辑使用抽屉。
- 禁用确认说明实际影响：影响各租户后续模型调用，已经打开的输出流可能继续。

## 首轮待确认的设计分支

1. 是否在 SaaS Forge 平台控制台增加“AI 模型”菜单与本地页面，沿用平台会话、客户端与运维权限；AI 服务继续拥有模型目录数据。此方案需要修改 `saas-forge/frontend/apps/platform-console` 和本仓库的模型更新接口。
2. 密钥录入与保存：原推荐为填写环境变量引用；用户追问“新增时不能直接填密钥吗？”，当前讨论直接输入 API Key 的方案，尚未确认其存储方式。需要明确与 ADR 0005 的差异，不能将该追问记为已经批准修改密钥存储边界。

确认后再据此实施；本文件尚未将推荐方案记为已接受的决策。

## 2026-11-15：直接输入密钥的讨论

- 技术上可以在平台新增/编辑表单接收 API Key；当前接口与运行时仅支持环境变量引用，不能只增加前端输入框。
- 若采用直接输入，需要同时设计服务端持久化与模型代理解密读取。表单首次提交后，后续页面只显示配置状态，不回传原密钥；编辑留空保留原值，显式填写才替换。
- 现有 ADR 0005 中“数据库只存引用”和“浏览器不接收原始密钥”需要为模型凭据重新界定；用户在浏览器主动输入与服务端将已保存密钥回传浏览器是不同的数据流。
- 已查证 SaaS Forge 没有可直接消费的公开 SDK 密钥存储能力。IAM 的 MFA 模块有用于 TOTP 的内部加密类，但属于平台实现；服务凭据保存的是不可逆摘要，也不适用于需要取出后调用供应商的 API Key。
- 推荐方案（待确认）：平台管理员直接输入模型 API Key，由 AI 服务加密后持久化；加密主密钥独立从部署环境注入，新增模型不再逐项修改环境变量。保留现有引用型模型的兼容读取，避免已有配置失效。本次只调整模型凭据，MCP 凭据仍遵循原有注入方式。
- 此方案改变了模型凭据的持久化边界，需要用户确认后更新或部分取代 ADR 0005；尚未实施，也未将推荐方案记为已接受。

## 拟定验收方向

- 平台管理员完成新增、编辑、启用、禁用；请求失败时展示错误，不伪造保存成功。
- 编辑普通字段和切换状态不要求重新提供既有密钥引用。
- 平台身份、权限检查和租户模型选择继续由已有服务契约约束，覆盖无权访问和租户身份访问的场景。
- 验证模型状态变化对租户可用模型列表的影响。
- 按承载工程的页面规范完成组件验证，以及桌面和笔记本宽度下关键状态的截图走查。

上述验收方向为待确认设计，不代表功能或测试已完成。
